## 什么是智能钱包追踪?

### 简单比喻

想象你在学校里有一门很难的数学课。你发现班上有几个同学总是能考高分。如果你能:
1. 找到这些"学霸"
2. 观察他们怎么做题
3. 学习他们的解题思路

那么你的成绩也可能会提高对吧?

**智能钱包追踪**就是这个道理!

- **智能钱包** = 那些在加密货币市场上总是能赚钱的人
- **追踪** = 观察他们买卖了什么代币
- **跟单** = 学习并模仿他们的交易

## 为什么要追踪聪明钱包?

### 1. 信息不对称

在加密货币市场上:
- ❌ 普通人:消息滞后,不知道买什么
- ✅ 聪明钱包:提前获得信息,早买早卖

如果你能跟着聪明钱包,就能缩小这个差距!

### 2. 降低风险

聪明钱包通常:
- 会仔细研究项目
- 会检查代币安全性
- 会分散投资降低风险

跟着他们走,比自己瞎买要安全得多。

### 3. 学习交易策略

通过观察聪明钱包,你可以学到:
- 什么时候买入
- 什么时候卖出
- 如何控制仓位
- 如何止损止盈

## 如何使用本工具?

### 第一步:安装工具

```bash
# 1. 克隆项目
git clone https://github.com/yourusername/gmgn-tracker.git
cd gmgn-tracker

# 2. 编译程序
cargo build --release

# 3. 程序在这里: ./target/release/gmgn-tracker
```

### 第二步:扫描聪明钱包

这是最重要的一步!

```bash
gmgn-tracker scan --chain solana --limit 10
```

**会发生什么?**
- 程序会访问 GMGN.ai 网站
- 获取 Solana 链上的钱包排行榜
- 按照收益率、胜率等指标筛选
- 给每个钱包打分(0-100分)
- 显示最优秀的 10 个钱包

**输出结果示例:**
```
=== 智能钱包排行榜 ===
钱包地址                                    总分     ROI分   胜率     多样性  活跃度
------------------------------------------------------------------------------------------------
#1  7xKz...9Abc                            92.5     95.2   75.0%   88.3     85.7
#2  8uYv...2Def                            89.1     88.9   80.5%   92.1     82.4
#3  9tWx...3Ghi                            85.7     82.3   68.2%   85.9     91.2
```

**如何理解结果?**
- **总分**: 越高越好(满分100)
- **ROI分**: 收益率得分,看赚钱能力
- **胜率**: 交易成功率,越高越稳定
- **多样性**: 持仓是否分散,降低风险
- **活跃度**: 交易频率,太低可能错过机会

### 第三步:查看钱包详情

找到感兴趣的钱包后,深入了解:

```bash
gmgn-tracker wallet 7xKz...9Abc --chain solana --holdings --trades
```

**会显示:**
- 7天和30天的详细数据
- 当前持仓列表
- 最近的交易记录
- 最大回撤(亏损幅度)

### 第四步:检查代币安全

**重要!** 在跟单前,必须检查代币是否安全!

```bash
gmgn-tracker check-token <代币地址> --chain solana
```

**输出示例:**
```
=== 代币安全检查 ===
代币地址: So11...aAbc
风险等级: 低风险
风险分数: 25/100

LP 销毁: ✓
蜜罐检测: ✓
可增发: ✗
所有权放弃: ✓
流动性: $125,000.00
持有者数量: 1,523
前10持有者占比: 28.5%

建议:
代币风险较低,但需注意以下问题:
  - 代币可增发,有通胀风险
建议: 小仓位试水,设置止损。
```

**关键指标解释:**

| 指标 | 含义 | ✓ 好 | ✗ 坏 |
|------|------|------|------|
| LP 销毁 | 流动性池是否锁定 | 开发者不能撤池 | 随时可能跑路 |
| 蜜罐检测 | 能否正常卖出 | 可以卖出 | 只能买不能卖 |
| 可增发 | 能否印钞 | 不能增发 | 可能稀释价值 |
| 所有权放弃 | 合约是否去中心化 | 已放弃 | 开发者有控制权 |
| 流动性 | 资金池大小 | 足够大 | 太小容易砸盘 |
| 持有者集中度 | 是否被少数人控制 | 分散 | 集中(容易被操控) |

### 第五步:设置监控(可选)

如果你想实时跟踪某个钱包:

```bash
gmgn-tracker monitor \
  --wallets 7xKz...9Abc,8uYv...2Def \
  --chain solana \
  --interval 60 \
  --security-check true
```

**这会:**
- 每60秒检查一次这些钱包
- 发现新交易时立即通知你
- 自动进行安全检查
- 给出跟单建议

## 理解评分系统

### 总分计算公式

```
总分 = ROI分×30% + 胜率分×25% + 一致性分×20% + 多样性分×15% + 活跃度分×10%
```

### 各项评分详解

#### 1. ROI评分 (30%) - 赚钱能力

**公式:** 基于7天和30天收益率的加权平均

**例子:**
- 钱包A: 7天ROI = 100%, 30天ROI = 200%
  - 7天分数 ≈ 73分
  - 30天分数 ≈ 88分
  - ROI分 = 73×0.4 + 88×0.6 = 82分

**如何理解:**
- 90+ 分: 超级赚钱机器,要小心是否可持续
- 70-90 分: 优秀,值得关注
- 50-70 分: 中等,可以观察
- <50 分: 收益一般

#### 2. 胜率评分 (25%) - 稳定性

**公式:** 直接使用胜率百分比

**例子:**
- 钱包A: 赢了70次,输了30次
  - 胜率 = 70/(70+30) = 70%
  - 胜率分 = 70分

**如何理解:**
- 80+ %: 非常稳定
- 60-80 %: 良好
- 50-60 %: 一般
- <50 %: 不如抛硬币

#### 3. 一致性评分 (20%) - 抗风险能力

**公式:** 基于最大回撤和 Sharpe 比率

**最大回撤示例:**
- 钱包从最高点 $10,000 跌到 $7,000
- 回撤 = ($10,000 - $7,000) / $10,000 = 30%
- 回撤越小越好!

**如何理解:**
- 回撤 <10%: 非常稳健
- 回撤 10-20%: 可接受
- 回撤 20-30%: 较大波动
- 回撤 >30%: 过山车,心脏不好别跟

#### 4. 多样性评分 (15%) - 分散投资

**原理:** 使用 HHI 指数(越分散越好)

**例子:**
- 钱包A: 100% 仓位买一个币 → 多样性分 = 0分(风险极大)
- 钱包B: 平均分配 4个币,每个25% → 多样性分 = 90分(很好)

**为什么重要?**
- 如果钱包把所有钱押在一个币上
- 那个币暴跌 = 全军覆没
- 分散持仓 = 降低风险

#### 5. 活跃度评分 (10%) - 交易频率

**公式:** 基于30天交易次数的对数函数

**例子:**
- 10次交易 → 约70分
- 30次交易 → 约85分
- 100次交易 → 约95分

**如何理解:**
- 太少: 可能错过机会,或者钱包已废弃
- 适中: 正常活跃
- 太多: 可能是机器人,或者过度交易

## 风险提示

### ⚠️ 跟单不是万能的!

#### 1. 聪明钱包也会失败

- 即使是最优秀的交易者也会亏损
- 过去的表现不代表未来
- 市场环境变化很快

#### 2. 存在信息滞后

- 你看到交易时,可能已经晚了
- 聪明钱包可能已经开始卖出
- 价格可能已经被拉高

#### 3. 代币安全检查不是100%准确

- 有些骗局很隐蔽
- 新型攻击手段层出不穷
- 即使检查通过,也要小心

### 💡 安全使用建议

1. **分散投资**
   - 不要全仓跟一个钱包
   - 不要跟单一个代币
   - 最好分散到5-10个不同项目

2. **控制仓位**
   - 单次跟单不超过总资金的5-10%
   - 高风险代币仓位更小(2-5%)
   - 永远保留现金储备

3. **设置止损**
   - 买入后立即设置止损点(如-20%)
   - 亏损到止损点立即卖出,不要犹豫
   - 保护本金是第一要务

4. **独立思考**
   - 了解你买的是什么
   - 不要盲目跟随
   - 有疑问就不要买

5. **持续学习**
   - 观察聪明钱包的策略
   - 分析成功和失败的原因
   - 逐步形成自己的交易系统

## 常见问题

### Q1: 扫描需要多长时间?

**A:** 通常10-30秒,取决于:
- 网络速度
- GMGN API 响应速度
- 筛选条件的严格程度

### Q2: 可以同时监控多少个钱包?

**A:** 建议不超过20个,因为:
- 太多会导致信息过载
- 难以及时响应每个信号
- 质量比数量重要

### Q3: 如何选择筛选条件?

**A:** 新手推荐设置:
```bash
--min-roi-7d 30      # 不要太贪心
--min-roi-30d 50     # 要求一定的长期收益
--min-win-rate 55    # 至少比抛硬币强
--max-drawdown 40    # 接受一定的波动
--min-trades 15      # 有足够的样本量
```

保守者可以提高标准,激进者可以降低标准。

### Q4: 代币安全检查显示"中风险"还能买吗?

**A:** 看情况:
- 如果只是"可增发"警告 → 小仓位可以试
- 如果是"蜜罐"警告 → 绝对不要买
- 如果是"流动性不足" → 除非你是早期投资者
- 如果是"持有者集中" → 风险很大,谨慎

### Q5: 扫描结果为空怎么办?

**A:** 可能的原因:
1. 筛选条件太严格 → 降低标准
2. 当前市场行情不好 → 等待更好的时机
3. API访问问题 → 检查网络连接
4. 配置文件错误 → 重新生成配置

### Q6: 如何判断一个钱包是真的聪明,还是运气好?

**A:** 看这几点:
- **交易次数**: 至少20+次,样本量要够
- **时间跨度**: 至少30天以上的历史
- **一致性**: 胜率是否稳定,不要只看总收益
- **回撤控制**: 最大回撤是否在合理范围
- **多样性**: 是否分散投资,不是all-in一个币

### Q7: 工具会自动交易吗?

**A:** **不会!** 本工具只提供:
- 信息收集
- 数据分析
- 风险评估
- 操作建议

**所有交易决策和操作都需要你自己完成**。这样设计是为了:
- 避免自动化交易的法律风险
- 让你保持对资金的完全控制
- 培养独立思考和决策能力
